# Subtle Pay — Card Visual Prototype

A standalone React + TypeScript + Vite visual prototype.

This version intentionally contains only a white 9:16 mobile canvas and one black rounded card with colorful sprinkle marks. It has no backend connection, API calls, authentication, wallet data, or previous frontend screens.

## Run locally

Requirements: Node.js 22 or newer.

```bash
npm ci
npm run dev
```

Open the local URL printed by Vite.

## Build

```bash
npm run build
npm run preview
```
